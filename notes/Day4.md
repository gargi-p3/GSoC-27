# Day 4 - Understanding Pull Requests

Today I learned:

1. A Pull Request (PR) is a request to merge proposed changes into another branch or repository.
2. Developers create separate branches to work on changes without affecting the main branch.
3. After making changes, developers commit and push them to GitHub.
4. A Pull Request allows other developers to review the proposed changes.
5. Maintainers can approve, request changes, or reject a Pull Request.
6. Once approved, the changes can be merged into the project.
